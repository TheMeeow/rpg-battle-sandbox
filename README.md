# C++ RPG Battle Sandbox

![C++](https://img.shields.io/badge/C++-17-blue.svg?style=flat&logo=c%2B%2B)
![CMake](https://img.shields.io/badge/CMake-Build-success.svg?style=flat&logo=cmake)

Изолированная консольная песочница для симуляции пошаговых боев и базового ИИ. Проект написан на **чистом C++ (Standard Library)** и использует систему сборки CMake.

---

## Архитектурная ремарка

Этот проект был создан как песочница для тестирования игровых механик без использования сторонних библиотек. 

Я отдаю себе отчет в том, что в реальном GameDev-продакшене архитектура выглядит иначе. Данный код не пытается заменить Gameplay Framework, ECS или систему акторов движка, а лишь демонстрирует моё понимание базовых архитектурных паттернов и подходов к организации кода на C++.

---

## Ключевые особенности и механики

### Преследование игрока (Player) ботом (Enemy)
Реализован классический паттерн отслеживания цели для ИИ. Враг хранит указатель на цель (игрока) в виде `std::weak_ptr`, что позволяет ИИ перед взаимодействием с целью динамически проверять, существует ли она в оперативной памяти (не отключился ли игрок от игры и т.п.)

### Система экипировки
Базовый абстрактный класс `Weapon` расширяется специализированным оружием. Для примера реализованы 2 типа оружия:
* `Sword` - оружие ближнего боя с механикой **износа** (деградация базового урона при использовании)
* `Bow` - оружие дальнего боя с механикой **расхода боеприпасов** (требует объекты `Arrow` в инвентаре для выстрела)

### Боевая система
Реализована возможность баттлов с поочерёдными атаками между любыми двумя сущностями типа MyActor. Результаты боёв выводятся в консоль.

### Динамическая инициатива
Очередность хода в бою высчитывается на основе дальности атаки персонажей (`GetAttackRange()`). При равной дальности преимущество определяется случайным образом.

## Структура проекта

Проект разбит на логические модули:
* `CoreTypes.h` - Глобальные структуры данных (DTO).
* `Weapons.h / .cpp` - Иерархия оружия и расчет урона.
* `Actors.h / .cpp` - Иерархия интерактивных сущностей (MyActor, Player, Enemy).
* `GameLogic.h / .cpp` - Игровой менеджер (боевая арена, сбор отчетов от ИИ).
* `main.cpp` - Точка входа и интеграционный тест механик.

## Сборка и запуск

### Требования

- Git.
- CMake версии 3.13 или новее. Команда `cmake` должна быть доступна в терминале.
- Для Windows: Visual Studio 2022 с компонентом «Разработка классических приложений на C++».
- Для Linux: GCC или Clang и Make.
- Для macOS: Xcode Command Line Tools.

### Пример сборки через терминал:
```bash
# 1. Клонирование репозитория
git clone https://github.com/TheMeeow/rpg-battle-sandbox.git
cd rpg-battle-sandbox

# 2. Генерация файлов сборки
cmake -S . -B build

# 3. Компиляция проекта
cmake --build build

# 4. Запуск приложения
./build/Debug/GameApp
```
